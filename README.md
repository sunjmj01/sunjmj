# sunjmj

## 这个仓库是干什么的

这个仓库是 dsh-superagent 研究原型的沙盒（sandbox）仓库，用于该原型的试跑与验证，例如在真实的 GitHub 仓库中从 issue 出发完成代码修改并提交 pull request。仓库内容以实验和测试为主，可能会随时调整，并不代表生产代码。

## What is this repository for?

This repository is a sandbox for the dsh-superagent research prototype. It is used for trial runs and validation of the prototype's end-to-end workflows against a real GitHub repository, for example starting from an issue, making code changes and opening a pull request. The contents are primarily experimental and for testing, may change at any time and are not production code.
